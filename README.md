# 電子契約システム（自社利用）

入居者との賃貸借契約や、訪問介護の利用契約などを、社内で電子的に締結・管理するためのシステムです。
契約書テンプレートの管理、契約相手への署名依頼、メール認証＋同意ボタン方式での電子署名、締結済み契約のPDF生成までを一通りカバーします。

## 主な機能

- **契約書テンプレート管理**　入居契約・訪問介護利用契約などのひな形を登録・編集。`{{key}}` 形式の差し込み項目に対応。
- **契約の作成**　テンプレートから契約を生成し、差し込み項目へ値を入力（作成時点の本文をスナップショット保存）。
- **電子署名・同意フロー**　署名者ごとの専用URLを発行。相手はブラウザで契約内容を確認し、同意のうえ画面上に手書きでサイン（スマホは指でサイン可）。
- **PDF生成・保存**　契約本文・手書き署名画像・署名記録（署名日時・IPアドレス）・証跡情報を含むPDFを生成。日本語フォント（Noto Sans JP）を埋め込み。
- **ユーザー／権限管理**　社内スタッフのアカウントを管理（管理者 / 職員）。
- **監査ログ**　作成・送信・閲覧・署名・締結などを日時・操作者・IPとともに記録。

## 技術スタック

- Next.js 14（App Router） / React 18 / TypeScript
- Prisma + SQLite（データベース）
- pdf-lib + @pdf-lib/fontkit（PDF生成）
- bcryptjs（パスワードハッシュ）、HMAC署名付きCookieによるセッション管理

## セットアップ

```bash
# 1. 依存関係のインストール
npm install

# 2. 環境変数の用意（.env.example をコピーして編集）
cp .env.example .env
#   - SESSION_SECRET は本番では必ず長いランダム値に変更してください
#   - APP_URL は署名リンクのドメインに合わせて設定してください

# 3. データベース作成 ＋ 初期データ投入（管理者・サンプルテンプレート）
npm run setup

# 4. 開発サーバー起動
npm run dev
#   → http://localhost:3000
```

### 初期ログイン

`.env` の `SEED_ADMIN_*` で指定したアカウントでログインします（既定値）。

| 項目 | 値 |
| --- | --- |
| メールアドレス | `admin@example.com` |
| パスワード | `admin1234` |

> 本番運用前に必ずパスワードを変更し、`SESSION_SECRET` を再設定してください。

## 利用の流れ

1. **テンプレートを用意**（「テンプレート」メニュー）。本文に `{{tenant_name}}` のような差し込み項目を入れておきます。
2. **新規契約を作成**（「契約」→「新規契約を作成」）。テンプレートを選び、差し込み項目と署名者（氏名・メール）を入力。
3. **署名依頼を送信**。契約詳細画面で「署名依頼を送信する」を押すと、署名者ごとの専用URLが有効になります。URLをメール等で相手に案内します。
4. **相手が署名**。相手はURLを開き、契約内容を確認 → 同意チェック → 画面上に手書きでサイン（PC・スマホ対応） → 確定。すべての署名者が署名すると契約は「締結済み」になります。
5. **PDFを保存**。締結後、契約詳細画面から締結済みPDF（署名記録・証跡入り）をダウンロードできます。

## ディレクトリ構成

```
prisma/
  schema.prisma     データモデル（User / ContractTemplate / Contract / Signer / AuditLog）
  seed.ts           初期管理者・サンプルテンプレート
src/
  lib/              db / auth / template差し込み / PDF生成 / 監査ログ / トークン
  components/       共通UI（バッジ・ナビ・コピー）
  app/
    login/          ログイン
    (app)/          認証必須エリア（dashboard / contracts / templates / users）
    sign/[token]/   署名者向け公開ページ（認証不要）
    api/contracts/[id]/pdf/   PDF生成エンドポイント
    actions/        Server Actions（auth / templates / contracts / sign / users）
  assets/fonts/     PDF用日本語フォント（Noto Sans JP, OFL）
```

## セキュリティと運用上の注意

- 署名用URLのトークンは推測困難なランダム値（24バイト）です。URLの取り扱いには注意してください。
- 署名操作は日時・IPアドレス・User-Agent とともに監査ログに記録されます。
- 本システムは「メール認証（専用URL）＋手書き署名方式（立会人型に近い簡易な電子署名）」を採用しています。
  電子帳簿保存法や電子署名法への適合性、本人確認の厳格さが求められる契約については、
  運用ルールや必要に応じた本人確認手段の追加をご検討ください。
- 既定では署名依頼メールの自動送信は行いません（URLを画面からコピーして案内する運用）。
  SMTP連携が必要な場合は `src/app/actions/contracts.ts` の送信処理に組み込めます。

## メール送信について（未実装の拡張ポイント）

MVPではメール自動送信は組み込んでいません。署名URLは契約詳細画面からコピーして案内します。
nodemailer などを用いた自動送信は今後の拡張として `sendContractAction` に追加できます。

## 補足

- データベースは SQLite（`prisma/dev.db`）です。少人数の社内運用を想定しています。
  PostgreSQL へ移行する場合は `prisma/schema.prisma` の `datasource` を変更してください。
- 依存パッケージのうち一部ビルドツール（postcss 等）に既知の軽微な警告がありますが、Next.js は 14系の最新パッチ（14.2.35）を使用しています。
