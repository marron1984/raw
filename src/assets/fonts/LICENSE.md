# 同梱フォントについて

- フォント名: Noto Sans JP (NotoSansJP-Regular.ttf)
- ライセンス: SIL Open Font License, Version 1.1 (OFL-1.1)
- 提供元: Google / Noto Project (https://github.com/notofonts/noto-cjk)

本フォントは OFL-1.1 に基づき再配布されています。
PDF生成時に日本語を表示するために同梱しています。

なお、配布元の OpenType(CFF/.otf) 版は pdf-lib のフォント埋め込みで
日本語グリフが正しく表示されない不具合があるため、TrueType(glyf/.ttf) 形式へ
変換した上で同梱しています（fonttools/cu2qu による変換、グリフ形状は同等）。
